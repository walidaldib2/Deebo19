# DEBOO16 — النسخة المحلية المؤقتة

هذه نسخة تعمل دون Supabase أو إنشاء مشروع خارجي. تحتفظ بالبيانات محليًا باستخدام IndexedDB داخل المتصفح.

## التشغيل
1. فك ضغط `DEBOO16_SOURCE.zip`، ثم ارفع محتويات المجلد مباشرة إلى جذر المستودع.
2. ارفع جميع الملفات مباشرة إلى جذر مستودع GitHub (لا تضعها داخل مجلد إضافي).
3. فعّل GitHub Pages من Settings > Pages > Deploy from a branch > main > /(root).
4. افتح رابط الموقع الناتج من GitHub Pages. استخدم HTTPS حتى يعمل تثبيت PWA وخدمة العمل دون اتصال بصورة أفضل.
5. يمكنك أيضًا تشغيله على الكمبيوتر من داخل مجلد الملفات عبر:
   `python -m http.server 8000`
   ثم افتح `http://localhost:8000`.

## حفظ البيانات
- تُحفظ السجلات في IndexedDB على نفس الجهاز والمتصفح.
- لا تمسح بيانات الموقع ولا تستخدم وضع التصفح الخفي إذا كنت تريد الاحتفاظ بالسجلات.
- لا تنتقل البيانات تلقائيًا إلى جهاز آخر أو متصفح آخر.
- من الإعدادات أنشئ نسخة JSON احتياطية بشكل دوري وانقلها إلى مكان آمن.
- استعادة النسخة تستبدل بيانات النسخة المحلية الحالية بعد التحقق منها، ويتم تنزيل نسخة من الحالة الحالية قبل الاستعادة.

## الطقس والاتصال
الطقس الحقيقي من Open-Meteo يحتاج اتصال إنترنت. بقية وظائف إدارة السجلات الأساسية تعمل محليًا بعد تحميل التطبيق.

## الملفات والمرفقات وإصدارات التسليم
- يمكن إرفاق ملفات فعلية بالمستندات من خزنة المستندات (15 ميجابايت كحد أقصى لكل ملف).
- النسخ الاحتياطي JSON يتضمن المرفقات وإصدارات تسليم الشفت، ويحوّل الملفات إلى بيانات قابلة للاستعادة.
- كل إنشاء أو تعديل لتسليم الشفت ينشئ إصدارًا محفوظًا يمكن مراجعته من سجل الإصدارات.
- مرور الدراجات يقبل خمس دراجات مختلفة كحد أقصى في اليوم، ويمنع تكرار الدراجة نفسها في التاريخ نفسه.

## حدود النسخة المحلية
هذه نسخة محلية لمستخدم واحد وعلى جهاز واحد. لا توفر مزامنة سحابية أو حسابات فريق أو صلاحيات متعددة الأجهزة. WebAuthn/البصمة والتوقيع الإلكتروني الموثق غير مفعّلين. يتوفر مولّد QR محلي للنصوص والروابط العربية ويحفظ PNG دون اتصال. يتوفر قفل واجهة اختياري برمز PIN محلي، لكنه لا يشفر قاعدة البيانات ولا يعد نظام مصادقة مؤسسيًا. خرائط الفروع تفتح عبر OpenStreetMap عند إدخال الإحداثيات، والتوقيع المتاح صورة مرسومة محليًا فقط. تصدير Excel متاح بصيغة Excel 2003 XML بامتداد XLS، وليس XLSX حديثًا. تتوفر تنبيهات داخل التطبيق، وروابط خرائط للفروع عند إدخال الإحداثيات، ومساحة توقيع مرسوم لتسليم الشفت. المستودع تطبيق ويب/PWA ولا يحتوي مشروع Android أو Gradle لإنتاج APK. لا تُستخدم كقاعدة تشغيل متعددة المستخدمين أو كبديل عن نظام خادم مؤمن.

## إصدار الملفات
نسخة التطوير الحالية DEBOO16 v10. تم تحديث اسم ذاكرة التخزين المؤقت لخدمة العمل حتى يحصل المستخدم على ملفات الواجهة الجديدة بعد النشر.

## الملفات
- `index.html`: واجهة DEBOO16.
- `style.css`: التصميم الكحلي والذهبي.
- `app.js`: التنقل والوظائف والطقس والتقارير.
- `db.js`: قاعدة IndexedDB المحلية والنسخ الاحتياطي.
- `qrcode.js`: مكتبة توليد QR محلية مع دعم UTF-8.
- `manifest.json`, `sw.js`, `icon.svg`: PWA والأيقونة.
- `FEATURES_STATUS_AR.md`: ملخص حدود الميزات.


## حماية الاستعادة — v6
يتم فحص بنية ملف النسخ الاحتياطي ومعرّفات السجلات والمرفقات وأحجامها قبل استبدال قاعدة البيانات. إذا كان الملف غير صالح تُرفض الاستعادة قبل تعديل البيانات الحالية.


## تحسينات الإصدار v7
- إضافة زر تثبيت PWA عند دعم المتصفح لحدث التثبيت، مع إرشاد بديل إلى قائمة المتصفح عند عدم توفر الطلب المباشر.
- إضافة فحص حالة الاتصال وحجم التخزين التقريبي وحالة طلب التخزين الدائم.
- إضافة طلب اختياري من المتصفح لحماية بيانات الموقع من الإزالة التلقائية؛ قرار الموافقة يظل للمتصفح.
- إضافة ملفات إعداد Capacitor (`package.json` و`capacitor.config.json`) لتجهيز تحويل الواجهة الحالية إلى حاوية Android. هذه الملفات لا تعني أن مجلد Android الأصلي أو APK قد تم بناؤهما.

## تجهيز Android لاحقًا
يتطلب ذلك جهاز بناء يحتوي Node.js وAndroid Studio وAndroid SDK. من جذر المشروع: `npm install` ثم `npm run android:add` ثم `npm run android:sync` ثم افتح المشروع عبر `npm run android:open`. بعد ذلك يلزم بناء APK من Android Studio واختباره على جهاز فعلي. لا يوجد APK مرفق في هذه النسخة.


## الإصدار v8
يتضمن الإصدار تحسين اتساق حفظ تسليم الشفت وإصداراته وسجل المراجعة في معاملة واحدة، مع تشديد التحقق من سلامة النسخ الاحتياطية قبل الاستعادة.

**تنبيه:** هذا مشروع PWA محلي. إعداد Capacitor موجود، لكن مجلد Android وملف APK لم يتم توليدهما أو بناؤهما في هذه البيئة.


### الإصدار v10 — القفل التلقائي
عند تفعيل PIN، يتم إخفاء واجهة التطبيق وإظهار شاشة القفل تلقائيًا عند انتقال التطبيق إلى الخلفية أو إخفاء الصفحة. أدخل PIN مرة أخرى للمتابعة. هذه حماية واجهة محلية وليست تشفيرًا لقاعدة البيانات.


### فحص المصدر
بعد تثبيت اعتماديات المشروع، شغّل `npm test` لفحص سلامة الملفات وإعدادات التشغيل وبعض قواعد التحقق الساكنة. هذا الفحص لا يُعد اختبارًا تفاعليًا على هاتف Android.
