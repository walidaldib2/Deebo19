# DEEB — النسخة المحلية وتجهيز Android

هذه نسخة تشغيل محلية لمستخدم واحد، وتُحفظ السجلات باستخدام IndexedDB على الجهاز والمتصفح. تم تجهيز مسار بناء Android باستخدام Capacitor وGitHub Actions؛ لكن ذلك لا يحوّل قاعدة البيانات المحلية إلى خدمة سحابية أو نظام متعدد المستخدمين.

## التشغيل على الويب
1. فعّل GitHub Pages من إعدادات المستودع إذا كنت تريد تشغيل نسخة الويب.
2. افتح رابط الموقع باستخدام HTTPS حتى تعمل ميزات PWA والعمل دون اتصال بصورة أفضل.
3. يمكن تشغيل المشروع محليًا بعد تثبيت Node.js والاعتماديات باستخدام `npm install`.

## حفظ البيانات
- تُحفظ السجلات في IndexedDB على نفس الجهاز والمتصفح.
- لا تنتقل البيانات تلقائيًا إلى جهاز آخر أو متصفح آخر.
- أنشئ نسخة JSON احتياطية بشكل دوري وانقلها إلى مكان آمن.
- استعادة النسخة تستبدل بيانات النسخة المحلية الحالية بعد التحقق منها، ويتم تنزيل نسخة من الحالة الحالية قبل الاستعادة.

## الطقس والاتصال
الطقس الحقيقي من Open-Meteo يحتاج اتصال إنترنت. وظائف إدارة السجلات الأساسية تعمل محليًا بعد تحميل التطبيق، مع بقاء الميزات التي تعتمد على خدمات خارجية بحاجة إلى اتصال.

## الملفات والمرفقات وإصدارات التسليم
- يمكن إرفاق ملفات فعلية بالمستندات من خزنة المستندات (15 ميجابايت كحد أقصى لكل ملف).
- النسخ الاحتياطي JSON يتضمن المرفقات وإصدارات تسليم الشفت، ويحوّل الملفات إلى بيانات قابلة للاستعادة.
- كل إنشاء أو تعديل لتسليم الشفت ينشئ إصدارًا محفوظًا يمكن مراجعته من سجل الإصدارات.
- مرور الدراجات يقبل خمس دراجات مختلفة كحد أقصى في اليوم، ويمنع تكرار الدراجة نفسها في التاريخ نفسه.

## حدود النسخة المحلية
هذه نسخة محلية لمستخدم واحد وعلى جهاز واحد. لا توفر مزامنة سحابية أو حسابات فريق أو صلاحيات متعددة الأجهزة. قفل PIN المحلي يحمي واجهة التطبيق فقط، ولا يشفر قاعدة البيانات ولا يعد نظام مصادقة مؤسسيًا. خرائط الفروع تفتح عبر تطبيق/موقع خرائط خارجي عند إدخال الإحداثيات، وليست خريطة تشغيل تفاعلية مدمجة. التوقيع المتاح صورة مرسومة محليًا فقط. تصدير Excel متاح بصيغة Excel 2003 XML بامتداد XLS، وليس XLSX حديثًا. لا تُستخدم النسخة كقاعدة تشغيل متعددة المستخدمين أو كبديل عن نظام خادم مؤمن.

## حالة Android وGoogle Play
- معرّف التطبيق: `com.deboo16.fieldops`، والاسم الظاهر: `DEEB`.
- يستخدم المشروع Capacitor 8، ويتم توليد مشروع Android أثناء مسار البناء الآلي؛ مجلد Android الناتج ليس محفوظًا ضمن ملفات المصدر الحالية.
- نجح فحص المصدر وبناء APK تجريبي وبناء ملف AAB في GitHub Actions.
- ملف APK الناتج نسخة Debug للاختبار، وليس إصدار Release نهائيًا.
- ملف AAB الذي تم إنتاجه في آخر بناء كان غير موقّع؛ لذلك لا يصلح للرفع إلى Google Play قبل إعداد مفتاح رفع وتوقيع الحزمة والتحقق منها.
- إعداد التوقيع في GitHub Actions يحتاج الأسرار الأربعة: `DEEB_UPLOAD_KEYSTORE_BASE64` و`DEEB_UPLOAD_STORE_PASSWORD` و`DEEB_UPLOAD_KEY_ALIAS` و`DEEB_UPLOAD_KEY_PASSWORD`. يجب حفظ ملف المفتاح وكلمات المرور بأمان وعدم رفعها إلى المستودع.
- نجاح البناء الآلي لا يغني عن اختبار التطبيق على أجهزة فعلية، ولا يضمن قبول Google Play. يلزم استكمال مراجعة الصلاحيات وسياسة الخصوصية وبيانات الأمان واختبارات الطباعة والموقع والنسخ الاحتياطي قبل النشر.

## فحوصات المشروع
بعد تثبيت الاعتماديات، شغّل `npm test` لفحص اختبارات الواجهة وقاعدة البيانات. كما يشغّل مسار البناء فحوصات صياغة JavaScript والتحقق من إعداد Android. هذه فحوصات آلية للمصدر والبناء، وليست بديلًا عن الاختبار التفاعلي على هاتف Android.

## الملفات الأساسية
- `index.html`: واجهة DEEB.
- `style.css`: التنسيق.
- `app.js`: التنقل والوظائف والتقارير.
- `db.js`: قاعدة IndexedDB والنسخ الاحتياطي.
- `qrcode.js`: إنشاء QR محليًا.
- `manifest.json`, `sw.js`, `icon.svg`: إعدادات PWA والأيقونة.
- `capacitor.config.json`: إعداد Capacitor.
- `configure-android-share.js`: إعداد استقبال المشاركة على Android.
- `prepare-android-icons.js`: تجهيز أيقونات Android وGoogle Play.
