# تحديث أولويات DEBOO16 — حزمة المظهر

هذه الحزمة تضيف:
- التحكم في حجم الخط من 14 إلى 22 بكسل مع حفظ الاختيار محليًا.
- الوضع الفاتح والداكن مع حفظ الاختيار محليًا.
- لا تغيّر قاعدة البيانات أو سجلات المرور أو منطق التصدير.

## طريقة التركيب على GitHub من الهاتف

1. افتح مستودع `walidaldib2/Deebo`.
2. ارفع `preferences.js` و`preferences.css` إلى جذر المستودع.
3. افتح `index.html` للتعديل وأضف داخل `<head>` بعد `style.css`:
   `<link rel="stylesheet" href="preferences.css">`
4. أضف قبل `</body>` وبعد `app.js`:
   `<script src="preferences.js"></script>`
5. افتح `sw.js` وغيّر اسم الكاش من `deboo16-local-v10-1` إلى `deboo16-local-v11`،
   وأضف `./preferences.js` و`./preferences.css` إلى قائمة CORE.
6. احفظ التعديلات (Commit changes). سير العمل سيبدأ بناء APK تلقائيًا.

## مهم بخصوص البصمة وExcel

- تصدير Excel موجود بالفعل في مركز التقارير باسم `DEBOO16-report.xls`، لذلك لم يتم استبداله.
- البصمة لم تُضف في هذه الحزمة. المشروع الحالي PWA مغلف بـ Capacitor ولا يحتوي إعداد Android أصليًا محفوظًا في المستودع. تفعيل بصمة Android بشكل صحيح يتطلب إضافة Capacitor Native Biometric plugin ثم إعداد Android وإعادة بناء واختبار على الهاتف. لا نضع زر بصمة شكليًا لا يعمل.
- احتفظ بنسخة احتياطية JSON من التطبيق قبل تثبيت أي نسخة جديدة.
